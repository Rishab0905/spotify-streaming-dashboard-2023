# Spotify Streaming Analytics Dashboard 🎵

## Overview

This project is an interactive Spotify Analytics Dashboard created using Power BI.
The dashboard analyzes streaming trends, top-performing tracks, artists, and audio characteristics to understand music consumption patterns.

## Tools Used

- Power BI
- Power Query
- Data Cleaning
- Data Visualization

## Dashboard Features

- Total Streams analysis
- Most streamed songs analysis
- Top artists by streams
- Top 10 all-time streamed tracks
- Music characteristics analysis:
  - Danceability
  - Energy
  - Acousticness
  - Valence
- Cross-platform performance comparison

## Key Insights

- Identified the highest streamed tracks and artists
- Compared streaming performance across platforms
- Analyzed how music characteristics changed over time
- Studied distribution of streams by musical keys
